## Owning source

The primary procedural source was a private review draft proven in a live bounded career profile; its filename, user context, and runtime paths were excluded from the public package. It supplied the intended authority boundary, registry-led search, normalization, employer-original verification, evidence comparison, triage grammar, stop conditions, and acceptance cases.

The installed skill replaces the draft's embedded source list with the accepted YAML registry and separates job-board discovery/onboarding from ordinary runtime searching.

## Integrity boundary

This skill subtree contains Markdown procedure, references, and one output template only. It contains no scripts, binaries, symlinks, package manifests, credentials, API clients, scheduled jobs, or executable connector code.

Static inspection cannot prove every conceptual phrase is unique. The skill is intentionally based on general procedures observed across several systems, but its operating contract, wording, data structures, authority, and output grammar were authored for the specialist rather than copied as a donor package.
