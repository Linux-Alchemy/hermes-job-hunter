# Release notes

## 0.15.0 — capability-parity pre-release

Hermes Job Hunter now packages the reusable career machinery proven in the private specialist profile without shipping the private profile itself.

### Included

- evidence and authority core;
- inert, adopter-configured source catalogue;
- source-registry maintenance and bounded job discovery;
- career matching and evidence-bank schemas with fictional examples;
- employer intelligence;
- application packets;
- résumé and cover-letter drafting;
- deterministic DOCX/PDF production with font, structure, page, text, metadata, containment, and rollback controls;
- GitHub portfolio, CV, and LinkedIn audits;
- credential-ROI decisions;
- synthetic discovery, application, rendering, and refusal fixtures;
- package, semantic privacy, provenance, binary, schema, plugin, and Git-history validation.

### Deliberately external

- real candidate evidence and application records;
- live source enablement and access dates;
- voice samples;
- OAuth credentials and authenticated Google access;
- private GitHub access;
- messaging, Kanban, cron, sessions, logs, and runtime memory;
- application submission, document upload, employer messaging, and public-profile mutation.

### Migration notice

Pre-release Git history was rewritten before publication to remove private author metadata. Existing old-history clones must follow the reset/cherry-pick procedure in [Release operations](docs/RELEASE_OPERATIONS.md); they must not merge or push the superseded history.
